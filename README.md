# Python Programming 🐍

A topic-wise collection of Python programs, examples, and practice exercises. This repository documents my learning journey through Python fundamentals, with each topic organized in a separate branch.

## Topics Covered

- Operators and expressions
- Conditional statements
- Loops
- Pattern printing
- Strings
- Lists and list comprehensions
- Tuples
- Sets
- Dictionaries

## Repository Branch Structure

The following are Git branches, rather than folders inside the main branch.

| Branch | Content |
|---|---|
| `main` | Repository overview and topic index |
| `Conditional-Statement` | Decision-making using `if`, `elif`, and `else` |
| `Dictionary` | Key-value pairs, dictionary methods, and examples |
| `Functions` | Function definitions, parameters, arguments, return values, and lambda functions |
| `List` | List creation, indexing, slicing, and methods |
| `List-Comprehension` | Creating lists using expressions, iteration, and conditions |
| `Loops` | Iteration using `for` and `while` loops |
| `OOPs` | Classes, objects, constructors, inheritance, encapsulation, polymorphism, and abstraction |
| `Operators` | Arithmetic, comparison, logical, and other Python operators |
| `Patterns` | Pattern-printing exercises using loops |
| `Set-Data-Type` | Sets, set methods, and set operations |
| `String-Data-Type` | String indexing, slicing, methods, and manipulation |
| `Tuple` | Tuple creation, indexing, packing, and unpacking |

## How to Explore

1. Open the branch dropdown above the repository file list.
2. Select the topic you want to study.
3. Browse the programs and learning materials available in that branch.
4. Download or clone the code to run and modify the examples.

## Run Locally

Install Python 3, then clone the repository using its URL:

```bash
git clone <repository-url>
```

Open the cloned repository:

```bash
cd <repository-folder>
```

Switch to a topic branch, for example:

```bash
git switch Loops
```

Run a Python file from that branch:

```bash
python <filename>.py
```

Replace the placeholders with your repository URL, folder name, and Python filename.
